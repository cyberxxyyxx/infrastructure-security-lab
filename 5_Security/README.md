# Cybersecurity Lab

## 1. Overview

This section documents cybersecurity projects and practical security experiments performed in the homelab.

The environment is designed for security monitoring, threat detection, network analysis and controlled security testing.

## 2. Security Infrastructure

| Component | Technology | Purpose |
|---|---|---|
| SIEM | Elastic Security | Security monitoring and event analysis |
| Firewall | OPNsense | Network security and traffic filtering |
| Proxy | Squid | Web filtering and access control |
| IDS/IPS | Suricata | Network intrusion detection |
| Testing | Kali Linux | Security testing and network scanning |
| Malware Lab | Isolated VM | Malware analysis |
| Active Directory Lab | GOAD | Active Directory security testing |
