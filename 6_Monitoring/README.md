# Infrastructure Monitoring

## 1. Overview

This section documents the monitoring infrastructure deployed in the homelab, focused on system performance, service availability and resource utilization.

## 2. Monitoring Stack

| Tool | Purpose |
|---|---|
| Prometheus | Metrics collection and monitoring |
| Grafana | Dashboards and data visualization |
| Node Exporter | Linux system metrics |
| Uptime Kuma | Service availability monitoring |

## 3. Monitoring Architecture

The monitoring environment collects infrastructure metrics from Linux servers and services and presents them through Grafana dashboards.

Main monitoring areas:
- CPU and memory utilization
- Disk and storage usage
- Network traffic
- System performance
- Service availability

## 4. Technologies

- Prometheus
- Grafana
- Node Exporter
- Uptime Kuma
- Docker
- Linux
